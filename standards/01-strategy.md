# 01 · Strategy & competition

Scope: goals, audiences, positioning, competitors, search demand and intent, page priorities. Output: [`project-brief.md`](../templates/project-brief.md) and [`url-map.csv`](../templates/url-map.csv).

Last verified: 2026-10

| ID | Level | Rule | Verify |
|---|---|---|---|
| STR-01 | MUST | The project brief is complete and signed off before design starts: business goals, audiences, offer, positioning, primary conversion per page type, KPIs with baseline and target, budget, deadline and constraints. | Signed brief |
| STR-02 | MUST | Audiences are defined by their job to be done: problem, trigger, objections, decision criteria and search language. The basis is evidence (interviews, sales and support data, reviews, search data), not assumptions. | Sources listed in brief |
| STR-03 | MUST | One positioning statement: for *[audience]* who *[need]*, *[brand]* is the *[category]* that *[key benefit]*, unlike *[alternative]*, because *[proof]*. It drives the home-page hero and the Organization description (GEO-05). | Brief; home page |
| STR-04 | MUST | Analyze 3–5 business competitors and 3–5 search competitors (domains that rank for the core queries) on offer, positioning, content depth, UX, trust signals, technical health and link strength. | Competitor table in brief |
| STR-05 | MUST | Keyword research per core topic: volume, difficulty, intent (informational, commercial, transactional, navigational), SERP features and whether an AI Overview appears. Group keywords into clusters and assign each cluster to exactly one URL in `url-map.csv`. | `url-map.csv` |
| STR-06 | SHOULD | For each money query, record from the live results what ranks: format (guide, list, tool, category, product, local pack), depth and freshness. This sets the page type and the content brief. | Content brief "SERP observations" |
| STR-07 | SHOULD | Content gap analysis: topics search competitors rank for and we don't, prioritized by business value × feasibility. | Gap list |
| STR-08 | MUST | The site type is chosen and its profile in [`site-types.md`](site-types.md) applied. | Brief |
| STR-09 | SHOULD | Prioritize pages by business value, demand and effort. Launch with the smallest set that covers the main conversion paths; no thin placeholder pages. | Prioritized `url-map.csv` |
| STR-10 | SHOULD | On existing sites, capture a baseline before work starts: traffic, conversions, rankings, Core Web Vitals, indexed pages and backlinks. | Baseline export |
| STR-11 | SHOULD | Record each target market's constraints: language, currency, legal requirements, payment and shipping norms. | Brief "Markets" |
| STR-12 | COULD | Entity audit: how search engines and AI assistants describe the brand today (knowledge panel, AI answers), and the gap to the positioning statement. | Prompt sample; SERP |
